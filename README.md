# 매물레이더

게임 키 · 구독 · 계정 · 기프트카드 매물을 가격순으로 비교하는 단일 HTML 사이트입니다. 모바일 브라우저에서 바로 실행됩니다.

**바로 열기 (모바일 원클릭):** https://raw.githack.com/smikoo1000-svg/Ended/market-radar/index.html

## 기능
- **실시간 매물**: CheapShark API로 Steam · GOG · Epic · Humble · Fanatical 등 공식·인증 PC 게임 스토어의 현재 가격을 불러옵니다.
  - 검색하면 싼 매물이 맨 위, 비싼 매물이 맨 아래로 정렬됩니다 (최대 300개).
  - 검색어가 없을 때는 `싼 매물` / `비싼 매물` 목록을 보여줍니다.
  - 매물마다 별점(스팀 리뷰 긍정 비율 → 별 5개), 리뷰 수, 메타크리틱, 딜점수, 판매처 신뢰도를 표시합니다.
  - 한글 게임명(예: 엘든링, 사이버펑크)은 영문 제목으로 자동 변환해 검색합니다.
- **마켓 전체 (312곳)**: 키 마켓, 기프트카드·충전, 공식 구독, 소프트웨어 키, 스킨 마켓, 계정·아이템 거래, 구독 공유, 종합몰·중고, 가격비교 사이트.
  - 검색어를 넣으면 각 마켓의 검색 결과로 바로 이동합니다 (가격순 정렬을 지원하는 곳은 낮은 가격순).
  - 마켓별 신뢰도 점수(S~D 등급)와 Trustpilot 이용자 별점 링크를 제공합니다.
- 원화 환산(실시간 환율), 다크 모드, 모바일 레이아웃.

## 실행
`index.html` 한 파일이 전부입니다. 위 링크로 열거나, 파일을 받아 브라우저에서 열면 됩니다.
